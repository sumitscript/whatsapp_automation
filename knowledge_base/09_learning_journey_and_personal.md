# Learning Journey, Personality and Fun Facts

I learn by building and sharing in public, from a 30-day MERN #CodeHostage challenge and LeetCode streaks to computer vision and AI projects. Here are stories and fun facts from my journey.

## My 30 Days #CodeHostage Challenge — Learning the MERN Stack in Public

I announced I was taking myself "hostage (not really)" for 30 days to learn the MERN stack consistently, inviting others to join with #CodeHostage. I followed Love Babbar's guidance.
- Days 1–3: internet basics (routers, switches, ISPs), website vs web app, HTML tags, semantic tags, Emmet, block vs inline, tables, HTML forms and input types, and the lesser-known datalist element
- Days 4–6: job application form project, resume mini-project with a details-based FAQ, head tag, SEO meta tags, favicons, linking CSS and JS
- Days 7–13: CSS (inline/internal/external), selectors, fonts, colors (RGB, hex, HSL), box model, display types, box-sizing, position values, size units (px, %, em, rem, vw, vh), float, clear, overflow
- Days 15–21: media queries, CSS variables, box and text shadows, CSS animations and transitions, 2D transforms, a Recipe Website project (Day 20), flexbox, positioning and dimensions
- I openly apologized when a Canva auto-post setup failed and my updates stopped after Day 15, then caught up on every missed day.

## The Day I Helped a Cybercrime Victim (#CodeHostage Day 14)

- On Day 14 of #CodeHostage I skipped coding to help a cybercrime victim being harassed by scammers.
- I filed a case on the victim's behalf, took legal action, and used ChatGPT to draft a stern warning to the scammers, who then stopped.
- My takeaway: technology can be a force for good, and technologists carry responsibility for digital safety and ethics.
